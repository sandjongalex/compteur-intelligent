Deux **présentations 16:9 de 7 diapositives** ont été fabriquées sous forme de fichiers `.pptx` entièrement modifiables avec notes du formateur :

- `AlexTech_M02_V01_Composants.pptx`

Ces binaires ont été fournis en téléchargement dans la conversation ChatGPT de préparation du Module 02. **Ils ne sont pas encore stockés sur GitHub.** Pour les conserver dans le dépôt, téléverser manuellement les deux fichiers dans le dossier `slides/` (GitHub > Add file > Upload files).

Les fichiers sources de construction et une archive téléchargeable ont été produits également dans la conversation.
