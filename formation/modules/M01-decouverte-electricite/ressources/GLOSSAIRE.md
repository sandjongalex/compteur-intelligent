# Glossaire débutant — Module 01

| Terme | Explication simple |
|---|---|
| Électricité | Ensemble des phénomènes liés aux charges électriques et à leur déplacement |
| Compteur énergétique | Appareil qui relève l'énergie consommée pendant une période |
| Tension (V) | Différence de potentiel entre deux points |
| Courant (A) | Débit de charges électriques dans un conducteur |
| Puissance active (W) | Rythme auquel de l'énergie est transférée ou consommée utilement |
| Énergie (Wh, kWh) | Quantité d'énergie utilisée au cours du temps |
| Capteur / module de mesure | Composant qui produit des informations sur un phénomène physique |
| PZEM-004T | Module numérique de mesure de grandeurs électriques utilisé dans notre projet |
| Microcontrôleur | Circuit programmable qui exécute les instructions du système |
| ATmega328P | Microcontrôleur chargé de lire, calculer et commander les périphériques |
| Firmware | Programme installé dans un équipement électronique |
| LCD 20×4 | Écran affichant 20 caractères sur chacune de ses 4 lignes |
| DS3231 (RTC) | Horloge temps réel qui fournit la date et l'heure |
| FRAM | Mémoire non volatile pouvant garder des enregistrements sans courant |
| GSM | Technologie de réseau mobile utilisée pour communiquer |
| GPRS | Service de transmission de données sur un réseau GSM compatible |
| SIM800L | Modem GSM/GPRS prévu pour l'envoi des relevés |
| Serveur | Ordinateur ou service logiciel qui reçoit et répond aux demandes d'autres appareils |
| API | Interface permettant l'échange de données entre programmes |
| Flask | Bibliothèque Python pour créer une application ou une API web |
| SQLite | Base de données embarquée dans un fichier du serveur de l'application |
| Jinja2 | Moteur de templates qui produit des pages HTML à partir de données |
| Navigateur | Logiciel comme Firefox ou Chrome pour afficher la page web |
| IoT (Internet des objets) | Équipements physiques connectés qui échangent des informations |

**Rappel sécurité :** un module de mesure secteur et une alimentation isolée correctement certifiée ne remplacent pas la qualification nécessaire aux manipulations électriques. Les premières vidéos n'exigent aucun travail sur une installation 230 V.
