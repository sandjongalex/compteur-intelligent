# PowerPoint du Module 03 — Préparation au tournage

Deux présentations **PowerPoint modifiables** ont été produites à partir des scripts et du plan M03. Elles comportent **8 diapositives 16:9 par leçon**, avec des **notes du formateur**.

| Présentation | Contenu | Contrôles |
|---|---|---|
| `AlexTech_M03_V01_Arduino_IDE_Compilation.pptx` | IDE 2, carte/port, setup-loop, Vérifier/Téléverser, erreurs | 8 diapositives, rendu et débordements vérifiés |
| `AlexTech_M03_V02_Premiere_LED.pptx` | LED interne D13, LED externe D8, résistance, sketches et exercice | 8 diapositives, rendu et débordements vérifiés |

**Disponibilité :** ces deux binaires PPTX et le script source `generer_m03_pptx.js` ont été remis dans la **conversation ChatGPT** sous forme de téléchargements et d'une archive ZIP. **Ils ne sont pas encore déposés comme fichiers binaires sur GitHub**. Les storyboards, scripts oraux, code Arduino, quiz et TP sont consultables ici sur GitHub.

Pour archiver les PPTX dans ce dépôt public, télécharger les fichiers depuis la conversation, puis ouvrir ce dossier `slides/`, cliquer sur « Add file → Upload files » et téléverser les deux PPTX. Ne pas publier des vidéos commerciales réservées aux étudiants dans un dépôt public.
