# M05 — Checklist de conception et tournage

**18 minutes maximum : M05-V01 9 min + M05-V02 9 min.** Pas de PowerPoint. Le formateur assure **l'enregistrement et la publication**.

## Contenus effectivement rédigés

- [x] Deux scripts de 9 min **cibles**, avec paroles, fichiers ouverts et gestes.
- [x] Six sketches Arduino pour construire les deux démonstrations par étapes.
- [x] Deux sketches corrigés des TP, distincts du code de départ.
- [x] Guides du branchement D2–GND, UART, anti-rebond et `millis()`.
- [x] Deux TP avec énoncés apprenant et corrigés formateur séparés.
- [x] Quiz de 10 QCM avec réponses, explications et banque JSON.
- [x] Guide de dépannage et [plan de tests](../ressources/PLAN_TESTS.md).
